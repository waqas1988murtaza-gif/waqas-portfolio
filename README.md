# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/f7b46e98-c44f-47a9-b35d-09389cd4a6c7

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`


## SEO upgrade

This portfolio includes a BeyondSEO-inspired static SEO implementation for GitHub Pages:
- Canonical URL
- Meta title/description/robots
- Open Graph and X/Twitter metadata
- Person, WebSite and BreadcrumbList JSON-LD
- robots.txt
- sitemap.xml
- Descriptive image alt text and semantic headings
- Meaningful counter fallbacks for users/crawlers when JavaScript is unavailable

GitHub Pages deployment does not run the BeyondSEO WordPress/PHP plugin itself; these files implement the relevant on-page and technical SEO controls directly in the static site.
